# Rwanda CleanEnergy Insights (RCEI)
## Comprehensive Data Dictionary & Microdata Schema

This document provides the exhaustive specification for all survey variables ingested across NISR's official datasets and the schema of derived metrics generated by the RCEI platform.

---

## 1. Primary Ingested NISR Microdata Variables

### 1.1 EICV7 (2024) Household Survey Microdata
**Source File:** `dataset/IECV7/Microdata/Cross_Section/CS_S01_S5_S7_Household.dta`  
**Sample Records:** 14,000+ households representing 3.3M expanded households.

| Variable | Stata Type | Label / Description | Domain Values & Interpretation |
| :--- | :--- | :--- | :--- |
| `hhid` | String / Long | Unique Household Identifier | Unique cluster-household key |
| `district` | Integer | Administrative District Code | `11` (Nyarugenge) to `57` (Kirehe) |
| `ur` | Byte | Urban / Rural Location | `1` = Urban, `2` = Rural |
| `s5cq22a` | Byte | Primary Cooking Fuel | `1` = Firewood (Traditional Biomass)<br>`2` = Charcoal (Traditional Biomass)<br>`3` = Gas / LPG (Clean Energy)<br>`4` = Biogas (Clean Energy)<br>`5` = Electricity (Clean Energy)<br>`6` = Kerosene<br>`13` = Crop Residues / Peat |
| `pov_jan` | Byte | Household Poverty Classification | `0` = Non-poor<br>`1` = Poor (includes extreme poor) |
| `epov_jan` | Byte | Extreme Poverty Binary Indicator | `0` = Non-extreme poor<br>`1` = Extremely poor |
| `weight` | Double | Household Expansion Weight | Normalized sample expansion multiplier |

### 1.2 Agricultural Survey (SAS 2024) Microdata
**Source Files:**
- `dataset/Agricultural Survey (SAS) 2024/Microdata/s0_agriculture.dta`
- `dataset/Agricultural Survey (SAS) 2024/Microdata/s9_livestock.dta`
- `dataset/Agricultural Survey (SAS) 2024/Microdata/s3_crops.dta`

| Variable | Survey Section | Description | Analytical Purpose |
| :--- | :--- | :--- | :--- |
| `hhid` | S0 / S9 / S3 | Agricultural Household ID | Household merge key |
| `district` | S0 / S9 | District Name | District name resolution to administrative ID |
| `owner` | S9 Livestock | Ownership Category | Identifies Smallholder (`Household`) vs. Commercial (`Big farmer`) |
| `s9q2` | S9 Livestock | Livestock Type | Filtered for cattle (`cattle`) |
| `s9q4` | S9 Livestock | Number of Cattle Owned | Filtered for $\ge 2$ head threshold for continuous 4–6 m³ domestic biodigester operation |
| `s3_q20*` | S3 Crop Harvest | Crop harvest weight in kg | Ingests plot harvests of maize, beans, rice, and coffee |

---

### 1.3 5th National Census (RPHC-2022) & EICV5 (2017) Anchors
- **RPHC-2022:** 100% complete national census enumeration establishing district-level ground-truth biomass vs. clean energy rates.
- **EICV5 (2017):** 7-year historical longitudinal baseline (`EICV5_Household.dta`) used to calculate empirical compound annual reduction rates (CAGR).

### 2.1 Field Definitions
| Field | Type | Unit | Description |
| :--- | :--- | :--- | :--- |
| `biomass_reliance_rate` | Float | Percentage (%) | Weighted proportion of households using firewood, charcoal, or crop waste as primary cooking fuel. |
| `clean_energy_rate` | Float | Percentage (%) | Weighted proportion of households using LPG, biogas, or electricity. |
| `poverty_rate` | Float | Percentage (%) | Poverty headcount rate (`pov_jan == 1`), household-weighted. |
| `extreme_poverty_rate` | Float | Percentage (%) | Extreme poverty headcount rate (`epov_jan == 1`). |
| `estimated_households` | Integer | Households | District total private households extrapolated via expansion weights. |
| `transition_priority_score` | Float | Index (0–100) | Priority index calculated as: `(biomass_rate * 0.5) + (poverty_rate * 0.5)`. |
| `census_2022_biomass_rate` | Float | Percentage (%) | Baseline biomass rate recorded during the 2022 Population and Housing Census. |
| `empirical_annual_biomass_reduction`| Float | Percentage Points | Annualized reduction rate observed between 2022 Census and 2024 EICV7. |
| `eicv5_2017_biomass_rate` | Float | Percentage (%) | Baseline biomass rate recorded during EICV5 (2017). |
| `historical_7yr_biomass_reduction` | Float | Percentage Points | Total percentage point biomass drop over the 7-year period (2017 to 2024). |
| `biogas_viable_ag_hh_pct` | Float | Percentage (%) | Percentage of agricultural households owning $\ge 2$ cattle (SAS 2024). |
| `est_biogas_viable_households` | Integer | Households | Estimated smallholder households viable for continuous 4–6 m³ domestic biodigesters. |
| `est_bioslurry_fertilizer_tons_year`| Integer | Metric Tons / Year | Projected annual yield of liquid and solid organic bio-slurry fertilizer (12 tons/hh/year). |
| `crop_residue_feedstock_tons` | Float | Metric Tons / Year | Total recoverable agronomic residue waste from maize, beans, rice, and coffee. |
| `pellet_potential_tons` | Float | Metric Tons / Year | Sustainable densified pellet production potential (50% recoverable fraction). |
| `recommended_clean_pathway` | String | Categorical | Tailored clean cooking transition pathway matching the district's resource profile. |
| `pathway_tag` | String | Categorical | Short tag for UI badges (*Urban / Rapid LPG*, *Livestock Bio-Slurry*, *Agri-Residue Pellets*, *Gasifier Biomass*). |
